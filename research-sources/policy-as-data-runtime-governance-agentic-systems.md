key_takeaways: "Policy as code governs the deployment gate but exits the room the moment an agent goes live, creating a runtime governance gap where production decisions are ungoverned and unauditable. Policy as data decouples rules into versioned policy bundles that agents bind to at runtime, eliminating deployment lag for policy updates and generating passport objects that cryptographically bind each decision to the exact rule version that governed it. The pattern redefines the architect's role from static boundary definition to active runtime infrastructure design."
