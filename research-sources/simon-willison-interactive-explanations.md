key_takeaways: "Simon's companion pattern to linear walkthroughs: when an algorithm's behavior is spatially or temporally complex (his canonical example: Archimedean-spiral word-cloud placement), a linear walkthrough documents structure but doesn't convey mechanics. Interactive explanations — animated, explorable HTML visualizations — let readers watch the algorithm execute step-by-step. Tools used: Claude Code for web + Claude Opus 4.6; output is a single-page HTML app with text input, animation controls, frame-by-frame stepping, PNG export. Not a replacement for linear walkthroughs — the two are complementary: walkthrough for 'how is this organized,' interactive for 'how does this behave.' Extends [[agent-generated-codebase-walkthrough-for-onboarding]]."
