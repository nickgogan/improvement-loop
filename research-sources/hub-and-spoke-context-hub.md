# Private Enterprise Context Hub — Hub-and-Spoke Skill Strategy

A detailed strategy document plus one hook script shared with Nick by the author on
2026-07-12, describing a production skill-organization and context-hub system at a large
enterprise. The system is best understood as an **agentic Work OS for a single role**: its
author (a technical account manager) built it to run their own work, then shared it
org-wide — so it demonstrates the same trajectory the engine is on (personal agentic
system → shareable, harness-served pack), from a different starting point than
CareerBuddy. Nick's stated intake interest: the skill organization primarily, plus the
role-routing hook, which he flagged as worth keeping for multi-agent systems that lack a
front-door agent. The repository itself is private, so the writeup and the
`UserPromptSubmit` role-routing hook are preserved locally at
`research-sources/raw/context-hub/` as the primary source material (all identifying
details anonymized in the KB). Part I covers the authoring side: the hub-and-spoke skill
taxonomy with its ≥8-sibling threshold, the TRIGGER:/SKIP: description grammar and
peer-deferral graph, the convergence-loop optimizer family, the deep-research-to-skill
build pipeline, the concept-family gap explorer, and the whole-tree architect. Part II
covers the backing store: the two-tree authoring/canonical model with its allow-list
durability contract, the sync pipeline, and the MCP server (`hub_*` tool surface) with
telemetry middleware wrapping every registered tool.
