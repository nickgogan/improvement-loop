key_takeaways: "A minimal session-opener prompt pattern ('First run the tests' or 'Run uv run pytest') used at the start of agent sessions to establish a testing-mindset and force the agent to discover test infrastructure before making changes. Four-word prompts intentionally minimal; encodes substantial engineering discipline. Defends against deploying untested AI-generated code and against agents skipping test considerations entirely. Complementary to red/green TDD: TDD prescribes HOW to write code; this pattern prescribes WHEN to verify existing code works — a precondition for safe agent-driven development.
