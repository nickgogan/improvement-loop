A seven-level maturity model progresses from manual chat context (L1) to a full shared business OS (L7). Critical patterns: skills should reference files in the second brain rather than embedding context copies; scheduled tasks maintain real-time context; CLAUDE.md plus per-subfolder index files route agents through growing vaults; weekly maintenance cadence prevents context drift. One person must own the context layer for the business OS to function."
