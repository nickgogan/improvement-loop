## Why We Watch

Newsletter and podcast featuring practitioners building production agent systems. Value is in orchestration patterns, multi-agent coordination, and governance approaches from teams operating at scale. Podcast guests often reveal implementation details not published elsewhere.

## Relevance Filter

The test: **does this content describe patterns from production agent systems that could improve MetaSystem's architecture or operations?**

**Include (maps to research dimensions):**
- Multi-agent orchestration, delegation, workflow composition (Dim 6)
- Agent identity, persona design, context file architecture (Dim 10)
- Human-agent authority boundaries, autonomy tiering, governance frameworks (Dim 9)
- Evaluation and reliability engineering for agent workflows (Dim 7)
- Context engineering at scale — memory, RAG, compaction in production (Dim 1)
- Sandboxing and execution isolation in production deployments (Dim 8)

**Skip:** Hiring/career content, fundraising/business news, general ML training research (pretraining, RLHF internals) without agent builder implications, hardware discussions, model comparisons that are benchmark-only without design-relevant takeaways, podcast episodes on non-agent topics.
