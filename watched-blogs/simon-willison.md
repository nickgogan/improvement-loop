## Why We Watch

High-volume practitioner blog with reproducible experiments. Simon surfaces novel MCP patterns, Claude Code usage techniques, and prompt engineering approaches often before official docs. Value is in the concrete, tested patterns — not opinion or commentary.

## Relevance Filter

The test: **does this post describe a concrete technique or tool pattern that MetaSystem could adopt?**

**Include (maps to research dimensions):**
- MCP server/client patterns, new MCP capabilities, tool integration techniques (Dim 4)
- Prompt engineering techniques with demonstrated results (Dim 3)
- Context window management, context file patterns, dynamic context injection (Dim 1)
- Agent design patterns — persona files, boot sequences, capability boundaries (Dim 10)
- Evaluation or verification approaches for agent outputs (Dim 7)
- Sandbox/isolation patterns for agent execution (Dim 8)

**Skip:** General web development (Datasette, SQLite, Django) unless specifically agent-relevant, personal updates, link roundups without extracted patterns, product reviews without transferable techniques, opinion pieces without concrete implementation detail.
