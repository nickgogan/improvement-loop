# DD-50

> **Amended by DD-103 (2026-06-18).** The clause placing active governance documents (values, principles, vocabulary, constitution) in `meta-system/governance/` is retired — those docs were distilled into `CHARTER.md` (root) and the originals archived at `archive/meta-system/governance/`. The authoritative vision/values source is now `CHARTER.md`; engine operating rules live in `systems/improvement-loop/governance/`. The research-database clause (IL-owned) is unchanged. DD stays Binding for its surviving data-access rules.

> **For agents:** DD-50 tells you the data access rules. Design Decisions are distributed to system-scoped `project-management/design-decisions/` folders (DD-55). System Log lives at workspace root. Governance documents (values, principles, vocabulary) live in systems/meta-system/governance/.
>
> [Updated 2026-04-05: s1-schema content moved to household-os/knowledge/reference/ and household-os/archive/s1-extraction/ per DD-58. The s1-schema directory no longer exists.]

## Core Decision

Mixing "Notion mirror" and "active working files" in one directory creates confusion about what's authoritative. This DD establishes a clean split:

| Content | Authoritative Location | s1-schema Status |
|---|---|---|
| Design Decisions (data) | System-scoped `project-management/design-decisions/` folders (DD-55) | Removed after promotion |
| Implementation Backlog (data) | `implementation-backlog/` (root) | Removed after promotion |
| System Log (data) | `system-log/` (root) | Removed after promotion |
| Values, Principles, Vocabulary | `systems/meta-system/governance/` | Mirror copy retained (read-only) |
| Constitution | `systems/meta-system/governance/constitution.md` | Mirror copy retained (read-only) |
| Architecture pages | `incubator/household-os/knowledge/reference/` | Moved from s1-schema per DD-58 |
| System Governance pages | `systems/meta-system/governance/` | Local-first authoritative |
| Research databases | `systems/improvement-loop/` | IL-owned |
