## What Changed from DD-35

DD-35 defined skills running on Perplexity Computer with Notion as the KB backend. DD-65 migrates the entire pipeline to:

- **Platform:** Claude Code (local, via `.claude/skills/`)
- **Data storage:** Local-first markdown files with YAML frontmatter in `systems/improvement-loop/`
- **Research backend:** Perplexity MCP server (`perplexity_search`, `perplexity_research`) + `WebFetch`
- **Skill inventory:** Replaced `research-codifier` (planned) and `system-applicator` (future) with `session-handoff` (active)

## Local KB Data Model

All KB data is stored as markdown files with YAML frontmatter:

| Database | Path |
|----------|------|
| Research Sources | `systems/improvement-loop/research-sources/` |
| Research Findings | `systems/improvement-loop/research-findings/` |
| Research Authorities | `systems/improvement-loop/research-authorities/` |
| Improvement Proposals | `systems/improvement-loop/archive/improvement-proposals/` |

- **Filename convention:** kebab-case slug of entry name + `.md`
- **Relations:** Use filenames in YAML lists (e.g., `sources: ["article-name.md"]`)
- **Discovery:** ripgrep on frontmatter fields (e.g., `rg -l '^priority: "P1"'`); no catalog files maintained — amended 2026-04-23 per session-61 cleanup sweep. The `_index.md` catalogs and the "Update the corresponding `_index.md`" rule were removed; frontmatter on each artifact is the source of truth.

## Pipeline

