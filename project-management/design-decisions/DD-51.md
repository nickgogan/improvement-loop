# DD-51

> **For agents:** DD-51 means there is one git repo at the MetaSystem root. Do not create nested git repositories inside systems or projects.

---

## Core Decision

The monorepo structure enables cross-system references, unified governance, and simpler agent navigation. Independent git repos inside systems create boundaries that agents must work around. For a personal system, the complexity of nested repos exceeds the benefit.

---

## Migration Path

1. Archive claude-build's standalone git history: `git log --oneline > archive/claude-build-git-history.log`
2. Remove the nested `.git/` directory from claude-build
3. Initialize (or confirm) a root-level git repository for MetaSystem
4. All future commits happen at the MetaSystem root level

---

## When to Revisit

- If a system needs to be shared with external collaborators who shouldn't see the full workspace
- If git history size becomes a performance issue (unlikely for a personal system)
