# DD-39

> **For agents:** DD-39 defines the codification stage -- the step between proposal approval and system-specific deployment.

---

## Core Decision

Approved improvement proposals are **codified as governing knowledge** in the Codified Practices page before system-specific application.

---

## Pipeline Position

Research -> Propose -> Evaluate -> Enhance -> [Human Gate] -> **Codify** -> Apply

The research-codifier skill (planned) distills approved proposals into:
- Codified Practices entries (governing knowledge)
- System-specific application notes
