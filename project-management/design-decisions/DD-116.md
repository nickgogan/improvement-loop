# DD-116

> **For agents:** session ops = PROGRESS.md (forward-only, cold-start) + HISTORY.md
> (shipped changelog) + Conventional Commits. Close sessions with `/session-handoff`.
> Never author a dated handoff file; never create a System Log entry.

## Problem

The engine recorded every session's outcome in four overlapping places — PROGRESS prose
(which had become a session-history archive paid at every cold start), a dated handoff
file, a System Log entry, and git. CareerBuddy (analyzed session 133) demonstrated a
materially cheaper model with one forward control surface. Separately, a KB pass over
Omnigent, Hermes, and OpenClaw (session 138) showed no reference system routes learnings
through a session store: session state is either coordination infrastructure (Omnigent;
for us, git + HISTORY) or raw feedstock distilled into a curated layer (OpenClaw's
Dreaming → MEMORY.md, Hermes' tiered memory; for us, DDs / knowledge/ / the planned
IB-172 OKF layer). A hand-written per-session log had no analog and no consumer.

## Decision rationale

- **One cold-start artifact.** Phase 0's DoD — a fresh session starts from PROGRESS.md
  alone — collapses the per-session tax of reconciling four records.
- **Route-then-compact over accumulate.** History, decisions, work, and research each
  have a canonical home; PROGRESS holds only what steers the next unit of work.
- **Retire, don't re-scope, the SL.** A learnings-only SL would keep a fourth live
  surface with no reference-system analog; the routing rule (DD / knowledge / IB by
  shape) covers its remaining job with surfaces that already exist.
- **Historical corpus preserved.** Entries are append-only history and potential
  distillation feedstock (OpenClaw model) — kept in place, read-only.

## Scope of execution (session 138)

- `HISTORY.md` backfilled (sessions 117–137 detailed + collapsed eras); PROGRESS.md
  restructured to the control-surface shape.
- `/session-handoff` rewritten reconcile-in-place (CareerBuddy `ops-session-handoff`
  adaptation; Rule-10 assessed PASS); dated handoffs archived; wake-up idiom + Session
  Ops section added to engine CLAUDE.md.
- Pre-commit hook: PROGRESS line-budget check added beside the DD-114/DD-115 checks.
- SL producer surfaces retired: `/sl`, `/track` (sl create), `/governance-audit`
  (SL proposals) carry retirement notes; `sl read`/`sl list` stay live.
