# DD-71

> **For agents:** DD-71 defines the four-verdict taxonomy for source triage. Every source gets exactly one verdict via the decision tree. Do not invent new verdicts. EXTRACT means "worth full extraction"; everything else means "not yet" or "not ever."

---

## The Constraint

Before committing to full research-loop extraction, every source must be triaged with exactly one verdict:

| Verdict | Meaning | Next Action |
|---------|---------|-------------|
| **EXTRACT** | Source likely has 3+ unlinked findings worth extracting | Queue for `/research-loop` (Pass 1 for articles, Pass 2 for videos with transcripts) |
| **SKIP** | Source has <2 extractable findings, or content is already covered | No further action. Record reason in triage report. |
| **DEFER** | Cannot determine density from available information (paywall, dead link, insufficient summary) | Revisit manually or with different access method |
| **LINK-ONLY** | Source's content is already captured by existing findings, but the source file isn't linked to them | Queue for `/linkage-repair` instead of extraction |

## Decision Tree

Applied in fixed order — first match wins:

```
1. Can I access the content?
   NO  --> DEFER

2. Does the content contain actionable patterns?
   (Named techniques, specific tools/configs, quantified results,
    or workflows with concrete steps. NOT opinions or overviews.)
   NO  --> SKIP

3. How many distinct patterns can I identify from a skim?
   3+  --> EXTRACT
   0-2 --> Continue to step 4

4. Do existing KB findings already cover the patterns I found?
   All covered, source not linked --> LINK-ONLY
   All covered, source linked     --> SKIP
   Some novel                     --> EXTRACT (if novel count >= 2)
                                      SKIP   (if novel count < 2)
```

## Why a Fixed Taxonomy

- **Prevents extraction sprawl.** Without triage, every source gets full extraction regardless of expected yield. The calibration data showed wide variance in source value (0 to 20+ findings per source).
- **Makes queue management tractable.** Four verdicts map to exactly four next-actions. No judgment calls at the queue level.
- **LINK-ONLY prevents redundant work.** The source quality audit found sources whose content was already in the KB but unlinkeed. Extracting again would create duplicates; linking fixes the actual problem.

## Actionable Pattern Filter

A pattern must be at least one of:
- A named technique with implementation steps
- A specific tool, configuration, or file path
- A quantified result (numbers, benchmarks, comparisons)
- A workflow with concrete steps

Opinions, overviews, and "X is important" statements are NOT patterns. This filter prevents low-signal findings from entering the KB.
