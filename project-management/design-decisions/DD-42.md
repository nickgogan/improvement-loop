# DD-42

> **For agents:** DD-42 establishes that cross-system operational databases -- databases that agents and humans frequently read, write, and query across all four systems -- are top-level peers in the Household Teamspace alongside Household OS, Meta-System, and the Improvement Loop.

---

## Promoted Databases

| Top-Level Page | Contains | Purpose |
|---|---|---|
| **Design Decisions** | DD DB (inline) | Canonical record of every architectural choice |
| **Implementation Backlog** | IB DB (inline), IB docs page | Active build queue and execution tracking |
| **Improvement Loop** | Improvement Proposals DB, Research DBs | IL runtime data |
| **System Log** | System Log DB (inline) | Audit trail across all systems |

---

## The Three-Layer Model

| Layer | What It Is | Examples | Access Pattern |
|---|---|---|---|
| **Operational/Runtime (UB3)** | Where humans and S2 agents do daily work | Tasks, Projects, Goals, Notes | High-frequency read/write |
| **Governance Infrastructure** | Cross-system databases tracking architectural state | DD DB, IB DB, Proposals DB, System Log DB | Frequent read/write by all systems |
| **Design-Time (Meta-System)** | Architecture, decision specs, governance docs | Architecture hub, DD spec pages, System Governance | Read-heavy reference |

---

## Decision Rule for Future Databases

A database should be a top-level peer if it meets ALL of:
1. **Cross-system scope** -- serves S2, S3, IL, and/or System Governance
2. **Active state** -- tracks mutable, evolving records
3. **High write frequency** -- agents regularly create or update entries

---

## Resulting Hierarchy

```
Household Teamspace
+-- Household OS (UB3)              <- Operational/Runtime
+-- Design Decisions                <- Governance Infrastructure
+-- Implementation Backlog          <- Governance Infrastructure
+-- Improvement Loop                <- Governance Infrastructure (DD-41)
+-- System Log                      <- Governance Infrastructure
+-- Meta-System                     <- Design-Time Reference
    +-- Intention & Trajectory
    +-- System Governance
    +-- Architecture
    +-- Design Decision Guidelines
    +-- Implementation
    +-- System Log (docs)
```
