# DD-48

> **For agents:** DD-48 defines the lifecycle for new projects. All new work starts in incubator/. Only proven, permanent infrastructure earns an S-number and moves to systems/.

---

## Core Decision

S-numbers (S1, S2, S3, etc.) signal permanence and importance. Not every project becomes permanent infrastructure. The incubator provides a low-commitment space for experimentation.

---

## Lifecycle

```
Idea -> incubator/{project-name}/ -> [proves value] -> DD -> systems/s{N}-{name}/
```

### Stage 1: Incubation

- Created via the bootstrap skill or manually
- Lives in `incubator/{project-name}/`
- Has its own CLAUDE.md with project-specific context
- No S-number assigned
- Light-touch conventions: move fast, document decisions, archive when done

### Stage 2: Promotion Decision

Promotion requires ALL of:
1. **Proven value** — the project has demonstrated ongoing utility
2. **Permanent scope** — it's an Area (ongoing responsibility), not a Project (has an end date)
3. **Design Decision** — a new DD documenting the system's purpose, scope, and boundaries
4. **Nick's approval** — human gate

### Stage 3: Graduation

- Project moves from `incubator/{name}/` to `systems/s{N}-{name}/`
- Assigned the next sequential S-number
- Receives full system treatment: CLAUDE.md, .claude/ config, architecture documentation

---

## Retirement

Projects that don't prove out are moved to `archive/` with a note on why. No shame in archiving — DD-02 says "archive aggressively."
