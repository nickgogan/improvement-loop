# DD-41

> **For agents:** DD-41 defines where the Improvement Loop's operational data and documentation live in the Notion hierarchy.

---

## Core Decision

The Improvement Loop has two distinct homes:

1. **IL operational page** (top-level peer): Contains ONLY the Improvement Proposals DB (inline).
2. **IL Architecture** (under Architecture hub): Contains all design-time documentation -- Overview, Pipeline Architecture, IL Skill Catalog, IL Vocabulary, AI Research DBs, DD specs.

---

## Page Hierarchy

**Operational (top-level):**
Improvement Loop -> Improvement Proposals DB (inline)

**Documentation (under Architecture):**
Meta-System -> Architecture -> Improvement Loop Architecture -> Pipeline Architecture, IL Skill Catalog, IL Vocabulary, AI Research, DD specs, Tool References
