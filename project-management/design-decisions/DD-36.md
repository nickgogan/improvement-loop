# DD-36

> **For agents:** DD-36 establishes that system evolution is driven by periodic external research, not ad-hoc decisions.

---

## Core Principle

System evolution is driven by **periodic external research**, not ad-hoc decisions. The Improvement Loop scans frontier patterns in agentic coding, prompt engineering, and context engineering, then proposes changes grounded in evidence.

---

## What This Is NOT

This principle does not prevent:
- **Urgent fixes** -- if something is broken, fix it immediately
- **Human-initiated improvements** -- Nick can propose changes outside the IL
- **Experimentation** -- two-way door changes can be tried without waiting for a research cycle
