# DD-57

> **For agents:** DD-57 retires the S-number naming scheme. Systems are now referenced by descriptive names: Household OS, Claude Build, Improvement Loop. Do not assign S-numbers to new or existing systems.

---

## Core Decision

The S-number scheme (S1 through S4) introduced sequential identifiers for systems. While useful during the initial four-system decomposition, S-numbers created artificial naming that obscured the actual purpose of each system. Systems now use natural descriptive names that communicate intent directly.

### The Three Systems

| System | Former S-number | Description |
|--------|----------------|-------------|
| Household OS | S1 + S2 | The product — frameworks, operations, knowledge base |
| Claude Build | S3 | Build system — produces schema and infrastructure |
| Improvement Loop | (none) | Self-improvement — research, proposals, codification |

### What This Changes

- No new S-numbers will be assigned
- The `incubator/ -> systems/s{N}-{name}/` promotion path (DD-48) is retired
- New systems promoted from incubator use descriptive names: `systems/{descriptive-name}/`
- Historical S-number references in existing DDs are preserved as-is; they are not retroactively rewritten
