# DD-73

> **For agents:** DD-73 locks the research taxonomy at 10 dimensions. Every finding gets exactly one. Do not create new dimensions without a DD amendment. After any dimension change, run `/dimension-rebalance` to reclassify affected findings.

---

## The Constraint

The research knowledge base categorizes all findings into exactly **10 dimensions**:

| # | Dimension | Covers |
|---|-----------|--------|
| 1 | **Context Engineering** | System prompts, context window management, RAG patterns, memory architectures |
| 2 | **Model Selection** | Model routing, capability matching, cost optimization, provider comparison |
| 3 | **Prompt Craft** | Prompt structure, chain-of-thought, few-shot patterns, prompt testing |
| 4 | **Tool Integration** | MCP servers, function calling, tool design, API integration patterns |
| 5 | **Intent Engineering** | User intent decomposition, goal specification, constraint expression |
| 6 | **Orchestration** | Multi-agent coordination, workflow routing, state management, error recovery |
| 7 | **Evaluation** | Output quality metrics, testing frameworks, benchmarking, regression detection |
| 8 | **Sandboxing** | Execution isolation, safety boundaries, permission models, container patterns |
| 9 | **Governance** | Audit trails, compliance, human-in-the-loop gates, policy enforcement |
| 10 | **Agent Design** | Agent architecture, persona patterns, capability composition, lifecycle management |

### Rules

- Every finding must be assigned **exactly one** dimension via the `category` frontmatter field.
- The authoritative dimension registry lives at `systems/improvement-loop/operations/references/research-dimensions.md`. It defines what each dimension covers, what to search for, and active queries.
- **New dimensions require a DD amendment** to this decision. Ad-hoc categories are not permitted.
- **Dimension changes trigger `/dimension-rebalance`** to reclassify affected findings. This is mandatory, not optional.

## Why

The taxonomy evolved through three expansions driven by findings that had no natural home:

| Session | Dimensions | Change Driver |
|---------|-----------|---------------|
| 1 | 5 | Initial set |
| 5 | 9 | Orchestration gap (31.6% of findings had no home) |
| 6 | 10 | Agent Design split from Orchestration |

The 10-dimension model provides complete coverage of the agentic systems landscape without excessive overlap. The two largest gaps that drove expansion were Orchestration (31.6% of findings) and Evaluation (14.9%). Locking the taxonomy prevents dimension creep while the explicit amendment process allows principled evolution.
