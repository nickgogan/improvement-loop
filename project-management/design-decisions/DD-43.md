# DD-43

> **Superseded by DD-45.** DD-45 broadens MetaSystem's role from governance container to active knowledge layer. This DD's rename decision still holds, but MetaSystem's scope is now defined by DD-45.

> **For agents:** DD-43 renames "System Documentation" to "Meta-System" and consolidates standalone DD spec pages into DD database page bodies. The DD database entry IS the spec -- no separate standalone page.

---

## Core Decision

The top-level design-time reference container is renamed from "System Documentation" to **"Meta-System"**. Simultaneously, standalone DD spec pages are consolidated into their corresponding DD database entry page bodies.

---

## Changes

### 1. Rename: System Documentation -> Meta-System
All references across the workspace are updated. Exception: System Log entries and Archive content retain original name.

### 2. DD Spec Page Consolidation
DD spec content migrated into DD database entry page bodies. Standalone pages moved to Archive.

### 3. Navigation Pattern Update
System Governance and system-specific Architecture pages direct agents to query the DD database.

### 4. Vocabulary Updates
"Meta-System" added to Governance Vocabulary.

---

## Rationale

1. **Naming accuracy.** "Meta-System" captures the active, governing nature.
2. **Single source of truth.** Eliminates dual-location pattern.
3. **Consistent access pattern.** Agents get metadata and spec from a single fetch.
4. **Reduced navigation tax.**
5. **Clean Architecture pages.**
