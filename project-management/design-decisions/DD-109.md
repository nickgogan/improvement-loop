# DD-109

> **For agents:** Engine skills live under `systems/improvement-loop/.claude/skills/`; the
> workspace-root `.claude/skills/` is **cross-system only**. A skill is the atomic unit of
> capability — add new capability as a skill with a `SKILL.md` contract. These conventions
> originate in Claude Build's DD-49 / DD-34 (now archived); this DD re-homes them as live IL
> governance so citations resolve.

---

## Core Decision

The session-122 audit found live docs (`CLAUDE.md`, `knowledge/guides/skill-authoring-guide.md`,
`knowledge/patterns/capability-type-selection.md`, `knowledge/templates/_index.md`) citing **DD-49**
and **DD-34** as governing authority for skill placement and the skill-as-capability-unit model.
Both DDs are Claude Build artifacts that moved to `archive/claude-build/` in the engine collapse, so
the citations no longer resolve to live governance.

The conventions themselves are still in force and still accurate to the current layout (verified:
root `.claude/skills/` contains only cross-system utilities; all engine research/codifier/librarian/
owner skills live under the engine). This DD adopts them as live IL governance:

1. **System-scoped skill placement** (DD-49 origin). Engine skills → `systems/improvement-loop/.claude/skills/`.
   Workspace-root `.claude/skills/` → cross-system skills only.
2. **Skills as the atomic capability unit** (DD-34 origin). A skill is the atomic unit of Claude
   Code capability, invoked as a (possibly parameterized) command; capability is added as a skill
   with a `SKILL.md` contract.

## Why

Re-homing (rather than leaving the citations pointing at archived Claude Build DDs, or dropping the
provenance) gives live docs a resolvable, live authority — which matters more now that the engine is
the sole system and agents navigate governance by following DD references. The originating DDs are
preserved in `archive/claude-build/` and named here as origin, so no history is lost.

## What this does NOT change

- It does **not** alter where any skill currently lives — it records the existing layout.
- It does **not** revive Claude Build or its other DDs; DD-49/DD-34 remain archived (origin only).
- It does **not** touch cross-system skill membership (which skills count as cross-system) beyond
  describing the current set.
