# DD-67

> **For agents:** DD-67 defines the two-pass extraction architecture. All sources get Pass 1. Only high-value sources (P1/P2) get Pass 2 with full transcript text. Never skip Pass 1; never assume summary-only extraction is sufficient for high-value sources.

---

## The Constraint

Research extraction operates in two mandatory passes with different inputs, outputs, and trigger conditions:

| Pass | Input | Output | When |
|------|-------|--------|------|
| **Pass 1: Headline Triage** | Perplexity summaries, WebFetch | 1-3 findings per source | All sources — the default extraction mode |
| **Pass 2: Transcript Deep Extraction** | Full transcript text (local `.md` files) | 10-20 additional patterns per source | P1/P2 sources, long-form videos (>15 min), or explicit user request |

## Why Two Passes

Calibration across 16 YouTube transcripts (2026-04-07) proved that summary-based extraction systematically misses implementation details:

- **Perplexity summary only:** ~65-85% miss rate
- **Perplexity Computer (summary of transcript):** ~30-45% miss rate
- **Full transcript extraction (Pass 2):** baseline (0%)

Implementation details are the #1 miss category (31% of all misses). Summaries capture headline concepts but strip configs, file paths, operational constraints, and workflow mechanics. Transcripts reveal ~8.4x more patterns than summaries.

## Pass 2 Triggers

Pass 2 is triggered when:
- A source is triaged as P1 or P2 after Pass 1
- The source is a long-form video (>15 min) with practitioner demonstrations
- The user explicitly requests deep extraction
- A transcript is available locally
