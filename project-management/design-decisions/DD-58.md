# DD-58


> **Superseded by [[DD-118]] (2026-07-12). Household OS was archived to Notion (DD-106); the consolidation this DD defined has no local referent.**
> **For agents:** DD-58 defines the merge of S1-Schema and S2-Operations into a single system called Household OS. The Household OS lives at `incubator/household-os/` and follows the fractal unit pattern. All former S1 and S2 content now lives here.

---

## Core Decision

S1-Schema (the Notion extraction mirror) and S2-Operations (the operational system) are consolidated into a single system called **Household OS**. The Household OS is the product itself — the frameworks, operational architecture, knowledge base, and governance that define how the household runs. It is not just a Notion implementation.

### New Folder Structure

```
incubator/household-os/
├── app/                          # The product — operational configs, automation rules
├── governance/                   # System-specific rules and constraints
├── knowledge/                    # The knowledge vault
│   └── reference/                # Architecture docs, system governance, schemas
│       ├── architecture/         # From S1-Schema extraction
│       └── schemas/              # Database schema definitions (JSON)
├── agents/                       # Operational agents for the Household OS
├── project-management/           # DDs (28) and IB items (95)
│   ├── design-decisions/         # Former S2 DDs (DD-01 through DD-28)
│   └── implementation-backlog/   # Former S2 IB items
├── operations/                   # Error tracking, events, lessons, logs
└── archive/                      # Completed/retired work
    └── s1-extraction/            # Original Notion extraction manifest, archived pages
```

### Where S1 Content Went

- **Architecture docs** → `knowledge/reference/architecture/`
- **Database schemas (JSON)** → `knowledge/reference/schemas/`
- **System governance docs** → `knowledge/reference/system-governance/`
- **Implementation guides** → `knowledge/reference/implementation-guides/`
- **Notion extraction manifest and empty databases** → `archive/s1-extraction/`

### Where S2 Content Went

- **28 Design Decisions** (DD-01 through DD-28) → `project-management/design-decisions/`
- **95 IB items** → `project-management/implementation-backlog/`
- **S2 operational architecture** → `knowledge/reference/architecture/s2-notion-operations/`
- **Agent configs and workflows** → `agents/`

### The Three-System Model

| System | Directory | Nature |
|--------|-----------|--------|
| Household OS | `incubator/household-os/` | The product — frameworks, operations, knowledge base |
| Claude Build | `incubator/claude-build/` | Build system — produces schema and infrastructure |
| Improvement Loop | `systems/improvement-loop/` | Self-improvement — research, proposals, codification |
