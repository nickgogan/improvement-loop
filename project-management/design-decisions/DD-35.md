# DD-35

> **For agents:** DD-35 defines the complete skill inventory of the Improvement Loop and each skill's read/write scope.

---

## Skill Inventory

| Skill | Phase | Status | Platform |
|---|---|---|---|
| research-loop | Research | Active | Perplexity Computer |
| research-proposer | Proposal | Active (v2.0) | Perplexity Computer |
| prompt-evaluator | Evaluation | Active | Perplexity Computer |
| prompt-enhancer | Enhancement | Active | Perplexity Computer |
| research-codifier | Codification | Planned | Perplexity Computer |
| system-applicator | Deployment | Future | TBD (likely Claude Code) |

---

## Access Model

| Skill | Reads | Writes |
|---|---|---|
| research-loop | Web sources, existing Findings (dedup) | Research Sources, Findings, Authorities |
| research-proposer | Findings (filtered), system docs (capped 8-10) | Improvement Proposals |
| prompt-evaluator | Target prompts/configs | Evaluation output (workspace files) |
| prompt-enhancer | Evaluation scorecards, original prompts | Enhanced prompts (workspace files) |
| research-codifier | Approved proposals | Codified Practices page |
| system-applicator | Codified practices, target configs | Target system files |
