# DD-76

> **For agents:** If a finding names multiple roles, classify as pattern. Codify the shape; let downstream instantiation produce specific agent templates.

---

## The Constraint

The Form Router applies a role-count discriminator when evaluating the agent form:

- **role_count = 1** with specific cognitive disposition → agent form is eligible
- **role_count > 1** → bias toward pattern. The finding describes a system of roles, and the stable layer is the structural shape, not any individual role.

This is a bias, not a hard gate. A single-role finding can still be overridden to pattern if cross-source confirmations converge on shape but diverge on role names (as in calibration row 4: specialized-parallel-agent-roles).

## Why

Validated through the session 21 agent exercise (specialized-parallel-agent-roles: 5 specialist roles → pattern because no canonical role) and confirmed across the 50-finding calibration set (session 22). Every multi-role finding in the calibration (rows 18, 28, 49) resolved cleanly to pattern. Zero agent classifications in 50 findings — the agent form activates only for single-role findings with specific dispositions, which did not appear in this sample.

The discriminator prevents loose agent-shaped language ("the dedup agent", "the perf agent") from routing to agent form when the underlying insight is structural.
