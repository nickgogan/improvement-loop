# DD-31


> **Superseded by [[DD-118]] (2026-07-12). DD-31 governed the Proposer stage that DD-80 eliminated; the identify → extract pipeline (DD-80) carries current behavior.**
> **For agents:** DD-31 defines how the Proposer scopes its work, assesses proposals, and structures its output.

---

## Assessment Dimensions

| Dimension | Question | Values |
|---|---|---|
| Door Type | Is this reversible? | One-way door / Two-way door |
| Implementation Complexity | How hard to build? | Low / Medium / High |
| Ops Impact | How much ongoing burden? | Low / Medium / High |
| Conflicts | Conflicts with other proposals? | Yes (with Conflict Group) / No |

---

## Proposer Pipeline Phases

1. Scope Determination
2. System State Reading
3. Grouping & Conflict Analysis
4. Cost & Complexity Assessment
5. Proposal Generation
6. Summary

Supports partial runs stopping after phase 3 for a human gate on conflicts.
