# DD-70

> **For agents:** DD-70 defines how findings reference each other. Use the `related_findings:` frontmatter array with the four relationship types. Cross-links are discovered via `/finding-crosslink`, not invented during extraction.

---

## The Constraint

Findings may reference other findings via a `related_findings:` array in frontmatter. Each entry specifies:
- The related finding's filename
- The relationship type (exactly one of four)

### Relationship Types

| Type | Meaning | Test |
|------|---------|------|
| **enables** | A makes B possible or significantly easier | "Could B work without A?" — if no, A enables B |
| **contradicts** | A and B recommend incompatible approaches | "Can you follow both A and B?" — if no, they contradict |
| **extends** | A builds on B, adding depth or a new dimension | "Is A a superset of B's advice?" — if yes, A extends B |
| **same-problem** | A and B address the same problem differently | "Do A and B have the same goal?" — if yes, same-problem |

### Schema

```yaml
related_findings:
  - finding: "context-window-compaction-strategies.md"
    type: "extends"
  - finding: "pre-compression-identity-pinning.md"
    type: "enables"
```

## Design Choices

- **Directional, not bidirectional.** A references B, but B is not required to reference A back. This avoids update cascades. `/finding-crosslink` discovers both directions independently.
- **Binary-testable types.** Each relationship type has a yes/no test question. This prevents subjective "related to" links that add noise without information.
- **Four types only.** Broader categories (e.g., "inspired by", "similar to") were rejected as too vague to be actionable. Four types cover the relationships that matter for the Proposer: what enables what, what conflicts, what extends, and what's an alternative approach.

## Discovery Process

Cross-references are discovered by running `/finding-crosslink`, not manually during extraction. The skill uses parallel subagent batches to evaluate finding pairs against the four binary tests.
