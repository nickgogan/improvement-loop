# IB-142: Design and implement meta-system agents

First agents for the meta-system agentic layer. Establishes the pattern for how agents are defined across all systems per DD-53.

## Scope Revision (2026-04-23)

The vault-curator agent's original scope included "maintains `_index.md` catalogs". That responsibility was retired in session 61 when most `_index.md` files were removed (DD-55/DD-56/DD-65/DD-74 amended the same session). The curator's remaining responsibilities:

- **Frontmatter validation** against `_schema.yaml` — ensures every artifact has required fields and valid controlled-vocabulary values.
- **Cross-reference integrity** — detects broken DD / IB / wiki-link references as the vault evolves.
- **Stale-content flagging** — surfaces artifacts whose `updated:` field hasn't changed but whose cited state (files, paths, counts) has drifted.

The vault curator is no longer a catalog-maintenance role; it's a schema-and-integrity role.
