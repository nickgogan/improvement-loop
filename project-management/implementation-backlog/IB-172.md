## Nick's framing (2026-07-12, verbatim intent)

Like humans, an agent system has different kinds of memory that need to be pulled in
for different situations — so different layers will require different on-disk storage
and retrieval mechanisms. Concrete sketch: research findings could get a semantic
index + graph lookup, with OKF as a more curated layer above it. Policies are then
needed for what to put where, when, and how to traverse across the memory layers.

Named inspiration: the Hermes and OpenClaw memory architectures (the Gbrain+Hermes
video was processed partly for this reason) — draw on how they architected their
memory components.
