# IB-96: Create Human Authority Matrix (system-level human/agent task routing)

> **For agents:** This IB item creates a Human Authority Matrix -- a system-level mapping of which task categories are always human-owned, always agent-executable, or either with explicit approval. This extends the Agent Topic Map's task routing into a formal, auditable matrix.

---

## Background

Identified during the March 2026 Perplexity audit of the Household OS. The audit found that while the Agent Topic Map has per-task routing and the Implementation Process MCP Capabilities section lists what agents can/can't do at the tool level, there is no domain-level human/agent authority mapping.

The current state is adequate for single-agent manual handoff (the current operating mode). This item becomes higher priority when moving to multi-agent coordination or increased autonomous delegation.

---

## Proposed Structure

A table with columns: Task Category | Domain | Authority Level (Always Human / Always Agent / Either + Approval) | Rationale | Source DD

Example rows:

- View configuration | Notion workspace | Always Human | MCP cannot configure views | DD-12
- Property schema changes | Notion workspace | Always Agent | MCP handles reliably | DD-12
- DD amendments | System governance | Always Human | Requires Nick's approval | DD-01
- Page content updates | Documentation | Either + Approval | Agent drafts, human reviews for structural changes | DD-11
- Emergency protocol triggers | System health | Always Human | Protocol 5 is human-judgment only | DD-18
