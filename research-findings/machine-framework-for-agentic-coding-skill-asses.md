# MACHINE Framework for Agentic Coding Skill Assessment

## What It Is
MACHINE is an acronym framework covering all skills required for elite agentic coding (excluding domain knowledge). M = Mapping: plan-mode architecture, bidirectional prompting, plan sizing, and decomposition into master/sub-plans. A = Agents: orchestration, parallelization, sub-agent spawning, human-in/out-of-loop decisions. C = Context Engineering: token optimization, managing the 5 context management techniques (sub-agent, /re, compaction, /handoff, /clear). H = Harness Engineering: tools, MCPs, hooks, CLAUDE.md management, slash commands. I = Intuition: pattern recognition for model failure modes, knowing when to intervene, detecting 'you are absolutely right' as a reliability collapse signal. N = Natural Language: prompt engineering, XML tags, constraint articulation, completeness, chain-of-thought, dictation. E = Engineering: security, version control, test-driven development, engineering fundamentals. The meta-skill is speed x autonomy: at 50x base agentic speed, a 10% improvement = 55x output; approaching 100% autonomy approaches infinite throughput.

## Why It Matters
There is no existing learning curriculum for agentic coding. This framework crystallizes where practitioners are weakest (typically Mapping and Context Engineering) and provides a directed learning roadmap. It also exposes that 'vibe coding' conflates all seven skills and optimizes for none.

## Why People Are Using It
Practitioners use it as a self-assessment checklist. It provides vocabulary for discussing agentic coding competency.

## Potential Alternatives
Other agentic coding frameworks from practitioners (fewer structured). Anthropic's own documentation covers some of these areas but not as a unified skill taxonomy.

## Potential Improvements
Quantitative benchmarks per skill level would allow more precise self-assessment. A structured curriculum mapping learning resources to each skill.

## Potential Failure Modes
Domain knowledge (not covered by MACHINE) remains the gating factor; strong MACHINE skills without deep domain knowledge still produce poor-quality agents in specialized domains.
