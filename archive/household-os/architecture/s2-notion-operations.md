The running operational system -- ICOR framework, orchestrators, lifecycle workflows, domain specs, and workspace structure.

**Core Architectural Principle:** ICOR is the operating system for S2. Every other framework is an application running on top of it.

The four ICOR stages -- Input, Control, Output, Refine -- form the backbone of S2. Other frameworks contribute specific capabilities within these stages:

- **PARA** provides the spatial taxonomy (where things live)
- **CODE** provides the knowledge lifecycle (how information becomes knowledge)
- **Zettelkasten** provides deep synthesis (atomic, evergreen, connected notes)
- **OKR** provides the strategic skeleton (why we do what we do)
- **GTD-Lite** provides execution mechanics (friction-free task handling)
- **OODA** provides the decision engine (how judgment is applied)
