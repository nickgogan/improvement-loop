# Synthesized Guides — Live Substrate (Tier 1)

End-directed playbooks produced by `/synthesize-guide`. Each guide aggregates multiple pattern-classified findings into a unified how-to document with embedded templates, worked examples, and pitfalls.

**These are live substrate, not staged drafts (DD-111, rename-in-place).** There is no downstream deployment target — the Librarian advisory layer (`/assess-*`, `/design-*`, `/ask-kb`, `/audit-artifacts`) composes them in place via the guide routing table. If the kernel later needs generalized asset-form definitions, they are distilled *from* these guides, never relocated out of here.

The guide routing table (`operations/references/guide-routing-table.md`) maps G-numbers to files and tracks synthesis status and staleness. Per-guide changelogs live in `changelog/`; resolved co-occurrence harvest queues are archived at `archive/guides/`.
